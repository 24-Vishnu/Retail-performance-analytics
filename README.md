# Retail Sales Data Analysis & Interactive Dashboard

A complete retail sales analysis project using **SQL, Python, and Power BI** to turn raw sales data into clear business insights.

## Overview

The goal of this project was to understand how the business is performing across sales, profit, customers, products, regions, segments, and shipping methods.

I worked through the project in stages — starting with data quality checks and SQL cleaning, followed by exploratory analysis in SQL and Python, and finally presenting the results through an interactive Power BI dashboard.

## Project Goals

- Clean and prepare raw retail sales data
- Check data quality and consistency
- Explore sales and profit performance
- Identify high-performing categories, regions, products, and customers
- Understand the relationship between discounts and profit
- Build an interactive Power BI dashboard
- Convert analysis into practical business recommendations

## Dataset

The dataset contains **9,994 records and 21 columns** covering:

- Order and shipping details
- Customer information
- Product information
- Geographic information
- Sales, quantity, discount, and profit
